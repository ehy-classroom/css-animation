04 · Easing

Was passiert

Der Ball beschleunigt im Fall und wird beim Steigen langsamer. Die Bewegung folgt sichtbar der Schwerkraft.

Neu gegenüber 03

Nur die Timing-Funktion ändert sich: ease-in statt linear. Weg und Dauer bleiben gleich. Weil die Richtung wechselt, läuft auch die Kurve rückwärts: Aus ease-in wird beim Steigen ease-out.

CSS

@keyframes fallen {
  from { transform: translateY(0); }
  to   { transform: translateY(144px); }
}

.ball {
  animation-name: fallen;
  animation-duration: 0.6s;
  animation-iteration-count: infinite;
  animation-direction: alternate;
  animation-timing-function: ease-in;
}

/* ease-in = cubic-bezier(0.42, 0, 1, 1) */
