Was passiert

Drei Fragen untereinander. Ein Klick klappt die Antwort weich auf, der Pfeil dreht sich mit. Ein weiterer Klick klappt sie wieder zu.

Neu gegenüber 12

Die Höhe auto lässt sich nicht animieren, weil der Browser zwischen einer Zahl und „auto“ nicht rechnen kann. Der Ausweg: ein Grid mit einer Zeile, deren Höhe von 0fr auf 1fr wechselt – das lässt sich animieren. Dazu dreht rotate() den Pfeil. Ein kurzes Skript setzt nur die Klasse .offen und meldet den Zustand an Screenreader.

Bedienung

Klick auf eine Frage, oder mit Tab ansteuern und Enter drücken.

CSS

.eintrag-koerper {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows 0.35s ease;
}

.eintrag.offen .eintrag-koerper {
  grid-template-rows: 1fr;
}

.eintrag-innen {
  overflow: hidden;
}

.eintrag.offen .pfeil {
  transform: rotate(-135deg);
}

JS

kopf.addEventListener('click', () => {
  const offen = eintrag.classList.toggle('offen');
  kopf.setAttribute('aria-expanded', offen);
});
