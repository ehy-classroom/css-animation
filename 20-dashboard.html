20 · Dashboard-Kacheln

Was passiert

Ein kleines Dashboard baut sich auf: Die Kacheln gleiten nacheinander herein, danach wachsen die Säulen des Diagramms eine nach der anderen.

Neu gegenüber 19

Staffelung ohne eine Regel je Element: Jede Kachel und jede Säule trägt ihre Nummer als Custom Property --i, die Verzögerung wird mit calc() daraus berechnet. Auch die Säulenhöhe kommt als --h aus dem HTML. Neu gestartet wird über die Klasse am Dashboard, wie in 19. Das schließt die Serie ab: Fast alles hier ist aus den vorigen Szenen zusammengesetzt.

Bedienung

„Wiederholen“ am unteren Rand der Bühne.

HTML

<div class="kachel" style="--i: 2">…</div>
<div class="saeule" style="--i: 4; --h: 100%">…</div>

CSS

@keyframes einblenden {
  from { opacity: 0; transform: translateY(1em); }
}
.laeuft .kachel {
  animation: einblenden 0.5s ease-out both;
  animation-delay: calc(var(--i) * 0.12s);
}

@keyframes wachsen {
  from { transform: scaleY(0); }
}
.laeuft .saeule-balken {
  height: var(--h);
  animation: wachsen 0.6s ease-out both;
  animation-delay: calc(0.5s + var(--i) * 0.08s);
}
