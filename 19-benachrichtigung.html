19 · Benachrichtigung

Was passiert

Ein Klick auf „Benachrichtigung senden“: Die Glocke in der Kopfleiste wackelt, ein Zähler ploppt auf und zählt hoch, rechts fährt ein Hinweis herein und nach einigen Sekunden wieder hinaus. Ein Klick auf die Glocke setzt den Zähler zurück.

Neu gegenüber 18

Drei kurze Animationen auf einen Auslöser. Das Aufploppen schießt über das Ziel hinaus, weil die cubic-bezier()-Kurve Werte über 1 hat. Der Hinweis fährt in einer einzigen Keyframe-Folge ein und aus. Und: Eine CSS-Animation startet nur neu, wenn ihre Klasse kurz entfernt war – das Skript zeigt, wie das ohne Neuladen geht.

Bedienung

Button am unteren Rand der Bühne, mehrmals klicken; Klick auf die Glocke.

CSS

.badge.ploppt {
  animation: aufploppen 0.45s
             cubic-bezier(0.34, 1.56, 0.64, 1);
}

@keyframes toast {
  0%   { transform: translateX(calc(100% + 32px)); }
  10%  { transform: translateX(0); }
  85%  { transform: translateX(0); }
  100% { transform: translateX(calc(100% + 32px)); }
}

JS

function neuStarten(element, klasse) {
  element.classList.remove(klasse);
  void element.offsetWidth;
  element.classList.add(klasse);
}

neuStarten(glocke, 'klingelt');
neuStarten(badge, 'ploppt');
neuStarten(toast, 'zeigen');
