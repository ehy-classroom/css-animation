Was passiert

Eine analoge Uhr zeigt die aktuelle Uhrzeit. Der Sekundenzeiger springt im Sekundentakt; per Button läuft er stattdessen fließend.

Neu gegenüber 17

Drehung um einen frei gewählten Punkt: transform-origin setzt ihn an den Fuß jedes Zeigers. steps(60) zerlegt eine Umdrehung in 60 Sprünge. Die Startzeit kommt als negative animation-delay – das Skript liefert dafür nur die Sekunden seit Mitternacht als Custom Property. Die zwölf Striche sind eine einzige Regel, gedreht um ihre Nummer --i.

Bedienung

Button am unteren Rand der Bühne.

CSS

.zeiger {
  transform-origin: 50% 100%;
}
@keyframes umdrehung {
  to { transform: rotate(360deg); }
}

.sekunde { animation: umdrehung 60s steps(60) infinite; }
.minute  { animation: umdrehung 3600s linear infinite; }
.stunde  { animation: umdrehung 43200s linear infinite; }

.zeiger {
  animation-delay: calc(var(--jetzt, 0) * -1s);
}

JS

const jetzt = new Date();
const sekunden = jetzt.getHours() * 3600
               + jetzt.getMinutes() * 60
               + jetzt.getSeconds();
uhr.style.setProperty('--jetzt', sekunden);
