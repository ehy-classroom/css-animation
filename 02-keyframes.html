02 · @keyframes

Was passiert

Eine Sekunde nach dem Laden fällt der Ball von selbst einmal nach unten und springt danach zurück in die Ausgangslage.

Neu gegenüber 01

Kein Auslöser mehr. @keyframes beschreibt einen Ablauf unter eigenem Namen, animation spielt ihn am Element ab. Ohne weitere Angabe gilt die Animation nur, solange sie läuft – daher der Sprung zurück.

Bedienung

Seite neu laden, um die Animation zu wiederholen.

CSS

@keyframes fallen {
  from { transform: translateY(0); }
  to   { transform: translateY(144px); }
}

.ball {
  animation-name: fallen;
  animation-duration: 0.6s;
  animation-timing-function: linear;
  animation-delay: 1s;
}
