14 · Ladeindikatoren

Was passiert

Zwei typische Ladeanzeigen: Ein Ring dreht sich, drei Punkte pulsieren nacheinander. Beide laufen endlos.

Neu gegenüber 13

Endlosschleifen ohne Auslöser wie in Serie 1, jetzt für die Oberfläche. rotate() mit linear dreht gleichmäßig, ohne zu stocken. Die Welle der Punkte entsteht aus einer einzigen Animation, die per animation-delay versetzt startet. Bei reduzierter Bewegung laufen beide langsamer statt gar nicht, weil sie Information tragen.

CSS

@keyframes drehen {
  to { transform: rotate(360deg); }
}

.spinner {
  animation: drehen 0.9s linear infinite;
}

.punkte span {
  animation: pulsieren 1.2s ease-in-out infinite;
}
.punkte span:nth-child(2) { animation-delay: 0.15s; }
.punkte span:nth-child(3) { animation-delay: 0.3s; }
