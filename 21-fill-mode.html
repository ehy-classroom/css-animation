Was passiert

Vier Bälle, dieselbe Animation: eine Sekunde warten, dann in 1,5 Sekunden von from nach to rollen, ein Durchlauf. Grau steht der Ball, wie ihn sein eigenes CSS beschreibt, orange zeigen ihn die Keyframes. Der einzige Unterschied ist animation-fill-mode.

Was man sieht

none: wartet grau in der Ausgangslage, springt beim Start nach from und am Ende zurück in die Ausgangslage. backwards: steht schon während der Verzögerung orange auf from, springt am Ende zurück. forwards: wartet grau, bleibt am Ende orange auf to stehen. both: kein Sprung, weder am Anfang noch am Ende.

Gut zu wissen

backwards wirkt nur mit Verzögerung, forwards nur, wenn die Animation endet (nicht bei infinite). Welcher Keyframe stehen bleibt, hängt von der Richtung ab: bei reverse oder bei alternate mit gerader Zahl an Durchläufen ist es from. Der gehaltene Zustand kommt weiter aus der Animation: Wird sie entfernt, gilt wieder das eigene CSS.

CSS

.ball {
  left: 160px;           /* Ausgangslage */
  background: #c9c6bd;   /* grau */
}

@keyframes rollen {
  from { transform: translateX(80px);  background: #e4572e; }
  to   { transform: translateX(440px); background: #e4572e; }
}

.ball {
  animation: rollen 1.5s ease-in-out 1s;
}

.ball.none      { animation-fill-mode: none; }
.ball.backwards { animation-fill-mode: backwards; }
.ball.forwards  { animation-fill-mode: forwards; }
.ball.both      { animation-fill-mode: both; }
