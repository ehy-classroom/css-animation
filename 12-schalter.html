12 · Schalter

Was passiert

Ein Schalter, wie er in Einstellungen vorkommt: Beim Klicken gleitet der Knopf zur Seite und die Bahn färbt sich ein. Ein weiterer Klick schaltet zurück.

Neu gegenüber 11

Der Zustand steckt in einer unsichtbaren Checkbox. Der Selektor :checked + .schalter-bahn reagiert darauf – wieder ohne Skript. Die transition macht aus dem Umspringen eine Bewegung. Weil alle Maße in em stehen, wächst der Schalter mit der Schrift.

Bedienung

Klick auf den Schalter oder den Text, oder mit Tab ansteuern und Leertaste drücken.

CSS

.schalter-knopf {
  transition: transform 0.25s ease;
}

.schalter-bahn {
  transition: background-color 0.25s ease;
}

.schalter-eingabe:checked + .schalter-bahn {
  background: #e4572e;
}

.schalter-eingabe:checked
  + .schalter-bahn .schalter-knopf {
  transform: translateX(1.5em);
}
