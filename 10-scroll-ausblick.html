10 · Ausblick: Scroll

Was passiert

Die Szene aus 06 im Takt des Scrollens: Beim Scrollen nach unten wandert der Ball von links nach rechts und springt dabei dreimal auf, mit Squash and Stretch und Schatten. Zurückscrollen spult die Bewegung rückwärts.

Neu gegenüber 09

Der Fortschritt kommt nicht aus der Zeit, sondern aus dem Scrollen (animation-timeline: scroll()). Dauer, Wiederholungen und Keyframes funktionieren weiter; drei Durchläufe verteilen sich auf den Scrollweg. Das ist eine neuere CSS-Funktion: Kennt ein Browser sie nicht, bleibt die Szene stehen. In GSAP heißt das Gegenstück ScrollTrigger.

Bedienung

Seite scrollen.

CSS

@supports (animation-timeline: scroll()) {
  .ball {
    animation: huepfen auto 3 both;
    animation-timeline: scroll();
  }
  .schatten {
    animation: schatten auto 3 both;
    animation-timeline: scroll();
  }
  .bahn {
    animation: rollen auto linear both;
    animation-timeline: scroll();
  }
}
