08 · Performance und Barrierefreiheit

Was passiert

Zweimal die Szene aus 06 nebeneinander: Ball mit Squash and Stretch, Schatten, Bahn. Links wird alles über Lage- und Größeneigenschaften bewegt (top, left, width, height), rechts nur über transform und opacity. Ist „Bewegung reduzieren“ eingestellt, hält auf beiden Seiten die seitliche Bewegung an; das Hüpfen läuft weiter.

Neu gegenüber 07

Kein neuer Effekt, sondern Qualität. transform und opacity kann der Browser als fertige Ebene verschieben und verformen. Lage- und Größeneigenschaften zwingen ihn bei jedem Bild, das Layout neu zu berechnen und neu zu zeichnen. Die Media Query prefers-reduced-motion berücksichtigt Menschen, denen Bewegung Beschwerden macht. Reduzieren heißt nicht unbedingt abschalten: Hier stoppt die große Ortsveränderung, die kleine Bewegung an Ort und Stelle bleibt.

Ausprobieren

Rendering-Bereich öffnen: In den Entwicklerwerkzeugen öffnet ⌘ ⇧ P (Windows: Strg ⇧ P) die Befehlszeile „Run Command“. Dort hinter dem > „rendering“ eintippen und „Show Rendering“ wählen. Alternativ: Menü ⋮ oben rechts in den Entwicklerwerkzeugen → More tools → Rendering. Der Bereich erscheint unten im Entwicklerwerkzeug. „Paint flashing“ färbt grün, was neu gezeichnet wird: links ständig, rechts kaum. Unter „Emulate CSS media feature prefers-reduced-motion“ lässt sich „reduce“ einstellen.

CSS

/* links: Lage und Größe */
@keyframes huepfen-layout {
  50% {
    top: 298px; height: 38px;
    width: 90px; margin-left: -13px;
  }
  /* weitere Stufen */
}

/* rechts: nur transform */
@keyframes huepfen {
  50% {
    transform: translateY(144px) scale(1.4, 0.6);
  }
  /* weitere Stufen */
}

/* beide Seiten: seitliche Bewegung anhalten,
   Hüpfen läuft weiter */
@media (prefers-reduced-motion: reduce) {
  .buehne .bahn {
    animation: none;
  }
}
