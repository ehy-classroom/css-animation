01 · transition

Was passiert

Ein Klick auf den Ball lässt ihn auf den Boden fallen, ein weiterer Klick lässt ihn wieder steigen. Die Bewegung ist gleichmäßig schnell.

Worum es geht

Eine transition macht den Wechsel zwischen zwei Zuständen weich. Sie braucht einen Auslöser – hier setzt ein Klick eine Klasse – und kennt nur Start und Ziel.

Bedienung

Klick auf den Ball, oder Tab und Leertaste.

CSS

.ball {
  transition-property: transform;
  transition-duration: 0.6s;
  transition-timing-function: linear;
}

.ball.unten {
  transform: translateY(144px);
}

JS

ball.addEventListener('click', () => {
  ball.classList.toggle('unten');
});
