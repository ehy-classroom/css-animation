15 · Karte umdrehen (3D)

Was passiert

Eine Kennzahl-Kachel dreht sich beim Klicken um die senkrechte Achse und zeigt auf der Rückseite Details. Ein weiterer Klick dreht sie zurück.

Neu gegenüber 14

Die dritte Dimension. perspective legt den Abstand des Betrachters fest, transform-style: preserve-3d hält Vorder- und Rückseite im Raum, backface-visibility: hidden blendet die abgewandte Seite aus. Die Bewegung selbst ist eine einfache transition auf rotateY().

Bedienung

Klick auf die Karte, oder mit Tab ansteuern und Enter drücken.

CSS

.karte {
  perspective: 60em;
}

.karte-innen {
  transform-style: preserve-3d;
  transition: transform 0.6s ease-in-out;
}

.seite {
  backface-visibility: hidden;
}

.hinten {
  transform: rotateY(180deg);
}

.karte.umgedreht .karte-innen {
  transform: rotateY(180deg);
}

JS

karte.addEventListener('click', () => {
  const umgedreht = karte.classList.toggle('umgedreht');
  karte.setAttribute('aria-pressed', umgedreht);
});
