07 · Steuern und Endzustand

Was passiert

Die Szene aus 06 – Ball mit Squash and Stretch, Schatten und Seitwärtsbewegung – lässt sich über drei Buttons steuern. „Anhalten“ friert alles ein, „Weiter“ setzt fort. „Landen“ lässt den Ball nach dem nächsten Scheitelpunkt aufsetzen und liegen bleiben; die Bahn hält an. „Abspringen“ lässt ihn vom Boden aus weiterhüpfen.

Neu gegenüber 06

animation-play-state hält laufende Animationen an und setzt sie an derselben Stelle fort. animation-fill-mode: forwards hält nach dem Ende der Landung den letzten Zustand fest – die Antwort auf den Rücksprung aus 02. Eine negative animation-delay lässt das Hüpfen mitten im Ablauf beginnen, am Boden. Das Skript setzt nur Klassen; mit dem Ereignis animationiteration wartet es auf den Scheitelpunkt, damit die Landung nahtlos ansetzt.

Bedienung

Buttons am unteren Rand der Bühne, per Maus oder Tastatur.

CSS

.ball {
  animation: huepfen 1.2s infinite;
  animation-delay: -0.54s; /* Start bei 45 % */
}

.buehne.angehalten .ball,
.buehne.angehalten .schatten,
.buehne.angehalten .bahn {
  animation-play-state: paused;
}

.buehne.gelandet .ball {
  animation: landen 0.9s;
  animation-fill-mode: forwards;
}

.buehne.gelandet .bahn {
  animation-play-state: paused;
}

JS

knopfLanden.addEventListener('click', () => {
  // warten, bis der Ball oben ist
  ball.addEventListener('animationiteration', () => {
    buehne.classList.add('gelandet');
  }, { once: true });
});

knopfAbspringen.addEventListener('click', () => {
  buehne.classList.remove('gelandet');
});
