06 · Animationen kombinieren

Was passiert

Der Ball hüpft wie in 05 und wandert dabei langsam nach rechts und links. Unter ihm wächst und schrumpft ein Schatten.

Neu gegenüber 05

Drei Animationen auf drei Elementen. Ball und Schatten haben dieselbe Dauer und dieselben Prozentstufen und laufen deshalb synchron. Die Seitwärtsbewegung liegt auf einem eigenen Element, der Bahn: Zwei transform-Animationen auf demselben Element würden sich überschreiben.

HTML

<div class="bahn">
  <div class="schatten"></div>
  <div class="ball"></div>
</div>

CSS

.ball {
  animation: huepfen 1.2s infinite;
}
.schatten {
  animation: schatten 1.2s infinite;
}
.bahn {
  animation: rollen 6s ease-in-out infinite alternate;
}

@keyframes schatten {
  0%, 100% { transform: scale(0.5); opacity: 0.1; }
  50%      { transform: scale(1.4, 1); opacity: 0.4; }
  /* weitere Stufen wie beim Ball */
}

@keyframes rollen {
  from { transform: translateX(-240px); }
  to   { transform: translateX(240px); }
}
