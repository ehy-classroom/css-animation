17 · Ringanzeige mit Zähler

Was passiert

Eine Ringanzeige füllt sich auf 72 Prozent, die Zahl in der Mitte zählt im gleichen Takt von 0 bis 72 hoch.

Neu gegenüber 16

Zwei neue Werkzeuge. Der Ring ist ein SVG-Kreis, dessen Strich über stroke-dashoffset wächst. Die Zahl ist eine Custom Property, die per @property einen Typ bekommt – erst dann lässt sie sich animieren. counter() gibt sie als Text aus. Gleiche Dauer und gleiches Easing halten beide synchron.

Bedienung

„Wiederholen“ lädt die Seite neu.

CSS

.ring-wert {
  stroke-dasharray: 100;
  stroke-dashoffset: 100;
  animation: ring-fuellen 2s ease-out 0.5s forwards;
}
@keyframes ring-fuellen {
  to { stroke-dashoffset: 28; }
}

@property --wert {
  syntax: "<integer>";
  inherits: false;
  initial-value: 0;
}
@keyframes zaehlen {
  to { --wert: 72; }
}

.ring-zahl {
  animation: zaehlen 2s ease-out 0.5s forwards;
  counter-reset: wert var(--wert);
}
.ring-zahl::after {
  content: counter(wert) " %";
}
