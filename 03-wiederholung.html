02 04

03 · Wiederholen und Richtung

Was passiert

Der Ball fällt und steigt endlos, immer gleich schnell. Das wirkt mechanisch, wie an einem Faden gezogen.

Neu gegenüber 02

Die Animation läuft endlos (animation-iteration-count), und jeder zweite Durchlauf läuft rückwärts (animation-direction: alternate). Dazu die Kurzschreibweise animation, die alle Angaben in einer Zeile zusammenfasst.

CSS

@keyframes fallen {
  from { transform: translateY(0); }
  to   { transform: translateY(144px); }
}

.ball {
  animation-name: fallen;
  animation-duration: 0.6s;
  animation-timing-function: linear;
  animation-iteration-count: infinite;
  animation-direction: alternate;
}

/* Kurzschreibweise */
.ball {
  animation: fallen 0.6s linear infinite alternate;
}
