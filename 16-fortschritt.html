16 · Fortschrittsbalken

Was passiert

Zwei Fortschrittsbalken. Der obere füllt sich ungleichmäßig wie bei einem Upload, steht kurz voll und beginnt von vorn. Im unteren läuft ein Stück endlos durch – für Vorgänge, deren Dauer unbekannt ist.

Neu gegenüber 15

Die Füllung wächst mit scaleX() statt mit width, also über transform wie in 08 empfohlen. transform-origin legt fest, dass sie links verankert bleibt. Im unteren Balken bezieht sich translateX() in Prozent auf die eigene Breite des Stücks.

CSS

.fuellung {
  transform-origin: 0 50%;
  animation: fuellen 5s ease-out infinite;
}

@keyframes fuellen {
  0%        { transform: scaleX(0); }
  35%       { transform: scaleX(0.4); }
  85%, 100% { transform: scaleX(1); }
  /* weitere Stufen */
}

@keyframes wandern {
  from { transform: translateX(-100%); }
  to   { transform: translateX(250%); }
}
