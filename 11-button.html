11 · Button

Was passiert

Ein Button reagiert auf drei Zustände: Unter dem Mauszeiger hebt er sich an und sein Schatten wächst, beim Klicken wird er eingedrückt, per Tastatur bekommt er einen Fokusrahmen.

Neu gegenüber 10

Beginn der zweiten Serie: Bewegung in der Benutzeroberfläche. Eine transition kann mehrere Eigenschaften zugleich weich wechseln, jede mit eigener Dauer. Die Auslöser liefern die Pseudoklassen :hover, :active und :focus-visible – ganz ohne Skript, anders als in 01.

Bedienung

Maus über den Button, klicken, oder mit Tab ansteuern.

CSS

.knopf {
  transition-property: transform, box-shadow,
                       background-color;
  transition-duration: 0.2s, 0.2s, 0.4s;
  transition-timing-function: ease-out;
}

.knopf:hover {
  transform: translateY(-3px);
}

.knopf:active {
  transform: translateY(1px) scale(0.98);
  transition-duration: 0.05s;
}
