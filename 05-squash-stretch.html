05 · Squash and Stretch

Was passiert

Der Ball fällt rund, staucht sich beim Aufprall stark und streckt sich beim Absprung weit nach oben. Auf dem Weg zum Scheitelpunkt wird er wieder rund.

Neu gegenüber 04

Statt from und to beschreibt eine Folge von Prozent-Keyframes den ganzen Sprung, mit eigenem Easing je Abschnitt. Die Verformung entsteht mit scale(); transform-origin legt den Bezugspunkt an den Fuß des Balls. Gestaucht wird beim Aufprall, gestreckt beim Absprung – im Fall bleibt der Ball rund. Stauchen und Strecken ist ein Grundprinzip des Trickfilms.

CSS

@keyframes huepfen {
  0%, 100% {
    transform: translateY(0) scale(1, 1);
    animation-timing-function: ease-in;
  }
  45% {
    transform: translateY(144px) scale(1, 1);
    animation-timing-function: linear;
  }
  50% {
    transform: translateY(144px) scale(1.4, 0.6);
    animation-timing-function: linear;
  }
  55% {
    transform: translateY(144px) scale(0.7, 1.4);
    animation-timing-function: ease-out;
  }
}

.ball {
  animation: huepfen 1.2s infinite;
  transform-origin: 50% 100%;
}
